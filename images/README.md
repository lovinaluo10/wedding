# 圖片資料夾

## 喜帖背板

- `bg-portrait.jpg`：直立（約 9:16），手機／直向預設
- `bg-landscape.jpg`：橫向（約 16:9），橫拿或寬度 ≥ 900px 時使用
- 替換時保持同檔名即可；切換邏輯在 `css/styles.css` 的 `.sky-bg`

## 如何替換真實合照

請把 3 張照片放到這個資料夾，檔名必須為：

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`

建議：

- 直式或接近正方形，解析度約 1200px 寬即可
- 單張小於 1MB，手機載入較快

`index.html` 的相簿 Modal 已預設使用以上路徑。尚未放入照片時，網頁會顯示復古佔位底圖。
